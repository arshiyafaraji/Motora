# MOTORA Frontend

این بسته فقط فرانت‌اند سایت MOTORA را شامل می‌شود.

## اجرا
1. پوشه `motora` را در مسیر دلخواه قرار دهید.
2. برای مشاهده ظاهر سایت، فایل `index.html` را با مرورگر باز کنید یا پوشه را روی یک وب‌سرور محلی قرار دهید.
3. ویدیوی پس‌زمینه هدر به‌صورت محلی از `header.mp4` بارگذاری می‌شود و به لینک خارجی وابسته نیست.

## فایل‌ها
- `index.html`
- `motora.css`
- `motora.js`
- `header.mp4`

## نکته اتصال به بک‌اند
امکاناتی مانند ورود، حساب کاربری، سفارش، پرداخت، نظرات و محصولات پویا برای عملکرد کامل به APIهای بک‌اند PHP نیاز دارند. این بسته شامل بک‌اند و دیتابیس نیست. برای عملکرد کامل، فرانت‌اند را کنار پوشه بک‌اند MOTORA در همان دامنه/مبدأ قرار دهید.
